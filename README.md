# MNIST Digit Classification Using Deep Learning

## Overview

This project focuses on handwritten digit recognition using the MNIST dataset and Deep Learning techniques. The system classifies digits from 0 to 9 using a Neural Network model built with TensorFlow and Keras.

---

## Objectives

* Build a digit classification model
* Train a neural network using MNIST dataset
* Evaluate model accuracy
* Predict handwritten digits

---

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Jupyter Notebook

---

## Dataset

The MNIST dataset contains:

* 60,000 training images
* 10,000 testing images
* 28x28 grayscale handwritten digit images

---

## Project Workflow

1. Import dataset
2. Preprocess data
3. Build neural network
4. Train model
5. Evaluate accuracy
6. Predict digits

---

## Model Architecture

* Input Layer
* Flatten Layer
* Dense Hidden Layer
* Output Layer (10 classes)

---

## Results

The model achieves high accuracy on handwritten digit classification.
